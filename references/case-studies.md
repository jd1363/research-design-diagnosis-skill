# 研究设计典型错误案例库

所有案例均来自真实论文开题/答辩中的常见问题，脱敏处理后作为诊断参考。

---

## 案例1：变量操作定义与假设不匹配

### ❌ 原始设计
```
研究问题：工作压力如何影响员工离职倾向？
研究假设：工作压力越大，离职倾向越高。
变量定义：
  - 工作压力：用"月加班时长（小时）"测量
  - 离职倾向：用成熟离职倾向量表（3题项）测量
```

### 诊断发现的问题
1. **概念内涵严重不匹配：** 工作压力是主观感知概念，用"加班时长"（客观行为）只能捕捉压力的一个来源，无法测量压力本身（有的人加班多但不觉得有压力，有的人加班不多但压力很大）
2. **效度威胁：** 可能出现"加班多→收入高→离职倾向低"的反向关系，导致假设检验出现假阴性
3. **经典错误类型：** 用"前因变量"代替"核心变量"

### ✅ 修正方案
```
变量重新定义：
  - 工作压力：采用Cooper等(1988)的工作压力量表，测量主观压力感知
  - 加班时长：可作为控制变量或工作压力的一个前因变量
逻辑链条：加班时长 → 工作压力 → 离职倾向
```

## 案例2：样本代表性与研究结论不匹配

### ❌ 原始设计
```
研究问题：中国企业员工的工作满意度与绩效的关系
样本：某互联网公司200名技术岗员工
结论：工作满意度与绩效呈显著正相关（r=0.35, p<0.001）
推广：该结论适用于中国企业员工
```

### 诊断发现的问题
1. **抽样框与推广范围严重不匹配：** 样本局限于"某互联网公司技术岗"，但结论推广到"中国企业员工"，差距过大
2. **样本同质性过高：** 同一家公司同一岗位，方差受限，可能低估真实相关（也可能高估）
3. **经典错误类型：** "方便样本+宏大结论"综合征

### ✅ 修正方案
```
方案1（收缩结论）：
  修改研究问题为"某互联网公司技术岗位员工工作满意度与绩效关系研究"
  结论限定于该类人群

方案2（扩大抽样）：
  采用多阶段分层抽样：不同行业（互联网/制造/服务）× 不同岗位（技术/管理/运营）
  目标样本量500+
```

## 案例3：对照组设计的致命缺陷

### ❌ 原始设计
```
研究问题：新教学方法是否能提高学生成绩？
实验设计：
  - 实验班：高一(3)班，使用新方法，由张老师授课
  - 对照班：高一(7)班，使用传统方法，由李老师授课
结果：实验班期末平均分比对照班高5分，差异显著
结论：新教学方法有效
```

### 诊断发现的问题
1. **混淆变量未控制：** 教师效应（张老师可能本来就比李老师教得好）完全混淆了教学方法效应
2. **非随机分配：** 自然分班不是随机分配，可能存在初始差异（3班可能本来就是重点班）
3. **缺少前测：** 没有基线数据，无法确定5分差异是教学方法导致的还是本来就存在
4. **经典错误类型：** 准实验设计却想得出因果结论

### ✅ 修正方案
```
最佳方案（真实验）：
  - 同一教师授课，学生随机分配到两种教学方法
  - 前测+后测设计

次优方案（准实验改进）：
  - 确保同一教师授课
  - 增加前测，用ANCOVA控制初始差异
  - 增加教师期望的盲法控制（让教师不知道哪个是实验组）
```

## 案例4：研究问题与假设完全脱节

### ❌ 原始设计
```
研究问题1：影响员工创新行为的因素有哪些？（探索性）
研究问题2：领导风格如何影响员工创新行为？（解释性）

研究假设：
  H1：变革型领导正向预测员工创新行为
  H2：领导-成员交换（LMX）正向预测员工创新行为
  H3：组织创新氛围正向预测员工创新行为
```

### 诊断发现的问题
1. **研究问题1没有对应假设：** 问题1是探索性的"有哪些因素"，但所有假设都是具体变量的验证，完全不匹配
2. **假设范围远小于问题范围：** 问题2问"如何影响"（隐含机制），但假设只检验了"是否影响"（主效应）
3. **经典错误类型：** 问题与假设的"两张皮"现象

### ✅ 修正方案
```
方案1（调整问题）：
  删除问题1，或改为文献综述部分
  问题2改为："变革型领导、LMX、组织创新氛围对员工创新行为的预测作用研究"

方案2（调整假设）：
  增加探索性研究设计（如质性研究或开放式问卷）来回答问题1
  问题2的假设补充中介/调节机制，真正回答"如何影响"
```

## 案例5：测量指标的效度灾难

### ❌ 原始设计
```
变量：组织承诺
测量指标（自编）：
  1. 我对公司有感情
  2. 我偶尔会想换工作（反向计分）
  3. 我愿意接受公司安排的加班
```

### 诊断发现的问题
1. **维度缺失：** Meyer & Allen的三维度模型（情感承诺、持续承诺、规范承诺）完全被忽略，只测了情感承诺的皮毛
2. **题项效度问题：**
   - 题项3混淆了组织承诺和服从文化（愿意加班可能只是怕被开除，不是承诺）
   - 题项2的"偶尔"定义模糊，不同人的"偶尔"标准差异很大
3. **信度灾难：** 3个题项很可能α<0.6，信度不足
4. **经典错误类型：** 用几个"想当然"的题项代替成熟量表

### ✅ 修正方案
```
方案1（最推荐）：
  使用Meyer & Allen (1997)的18题三维度量表，已在中国情境下验证
  三个维度：情感承诺、持续承诺、规范承诺，各6题

方案2（压缩版）：
  使用缩短版三维度量表（每个维度3题，共9题）
  必须报告验证性因子分析结果支持三维结构
```

## 案例6：中介效应的链条断裂

### ❌ 原始设计
```
研究模型：X → M → Y
X：变革型领导
M：工作投入
Y：任务绩效

假设：
  H1：变革型领导正向预测任务绩效
  H2：工作投入在变革型领导与任务绩效之间起中介作用
```

### 诊断发现的问题
1. **中介链条的逻辑不清晰：** 变革型领导为什么通过工作投入影响绩效？理论机制阐述不足
2. **缺少直接效应的理论说明：** 是部分中介还是完全中介？理论依据是什么？
3. **混淆变量风险：** 可能存在X→Y同时影响M的反向因果，或存在混淆变量同时影响三者
4. **经典错误类型：** "随便找个变量放中间"的中介综合征

### ✅ 修正方案
```
改进后设计：
  1. 补充理论机制：基于社会交换理论——变革型领导通过个性化关怀（X的维度）提升员工的社会交换感知，进而增加工作投入（M），最终体现在绩效上（Y）
  2. 明确中介类型：理论上预期是部分中介，因为变革型领导还可能通过其他路径（如资源供给、目标清晰化）影响绩效
  3. 纵向设计增强因果推断：三时点测量（T1:X, T2:M, T3:Y），降低反向因果风险
```

## 十大经典错误速查表

| 错误类型 | 典型表现 | 严重程度 |
|---------|---------|---------|
| 1. 操作定义漂移 | 假设说A，变量测的是B | 🔴 致命 |
| 2. 方便样本+宏大结论 | 样本很小很特殊，结论很大很普遍 | 🔴 致命 |
| 3. 混淆变量完全替代核心变量 | 教师效应替代教学方法效应 | 🔴 致命 |
| 4. 问题与假设两张皮 | 有问题无对应假设，有假设无对应问题 | 🟡 严重 |
| 5. 自编题项替代成熟量表 | 用3个"想当然"题项代替经过验证的量表 | 🟡 严重 |
| 6. 中介效应无理论机制 | X影响M影响Y，但是why？ | 🟡 严重 |
| 7. 样本量不足导致检验力低下 | 回归分析只有50样本，SEM只有100样本 | 🟡 严重 |
| 8. 变量维度缺失 | 组织承诺只测情感承诺，忽略持续和规范 | 🟡 严重 |
| 9. 缺少控制变量导致虚假相关 | 收入同时影响X和Y，未加控制 | 🟢 中等 |
| 10. 假设无方向性 | X与Y相关，但是正还是负？ | 🟢 中等 |

## 不同阶段的诊断重点

| 研究阶段 | 重点诊断内容 |
|---------|-------------|
| **开题阶段** | 研究问题-假设-变量的匹配性，变量操作定义的合理性，样本量规划 |
| **数据收集前** | 测量工具的效度/信度依据，抽样方案的可行性，对照组设计的严谨性 |
| **数据分析前** | 统计方法与研究假设的匹配性，控制变量选择的合理性 |
| **论文写作** | 结论范围与样本代表性的匹配性，局限性说明的充分性 |
