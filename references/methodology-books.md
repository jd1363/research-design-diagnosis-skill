# 研究方法论经典参考书单

## 研究设计基础

### 📖 《研究设计与社会测量导引》（Designing Social Research）
- **作者：** Norman K. Denzin
- **核心贡献：** 研究设计的三角验证原则
- **诊断要点引用：**
  - "一个好的研究假设必须同时具备可证伪性和具体性"
  - "变量操作定义的黄金标准：两个独立研究者使用该定义能得到相同测量结果"

### 📖 《社会研究方法》（The Practice of Social Research）
- **作者：** Earl Babbie
- **核心贡献：** 测量效度与信度的经典定义
- **诊断要点引用：**
  - 内容效度、效标效度、建构效度的三层检验标准
  - 样本量计算公式：n = Z² * p * (1-p) / e²
  - 方便抽样的局限性与适用场景

### 📖 《研究设计：定量、定性与混合方法路径》
- **作者：** John W. Creswell
- **核心贡献：** 三种研究范式的设计逻辑
- **诊断要点引用：**
  - 定量研究假设的"方向性原则"
  - 定性研究的"问题引导而非假设引导"原则
  - 混合方法研究的时序设计（解释性/探索性/三角设计）

## 量表与测量

### 📖 《量表编制：理论与应用》（Scale Development）
- **作者：** Robert F. DeVellis
- **核心贡献：** 量表开发的黄金标准流程
- **诊断要点引用：**
  - 探索性因子分析样本量要求：题项数的5-10倍
  - 验证性因子分析样本量要求：至少200，理想500+
  - Cronbach's α系数解读：>0.9优秀，0.8-0.9良好，0.7-0.8可接受，<0.6需修订

### 📖 《心理测量学》
- **作者：** 戴海崎 等
- **核心贡献：** 国内最权威的测量教材
- **诊断要点引用：**
  - 难度、区分度的计算方法
  - 项目反应理论（IRT）的适用条件
  - 经典测量理论的局限

---

## 实验设计

### 📖 《实验心理学》
- **作者：** Barry H. Kantowitz
- **核心贡献：** 实验设计的逻辑基础
- **诊断要点引用：**
  - 内部效度的8个威胁因素：历史、成熟、测验、工具、统计回归、选择偏差、被试流失、选择-成熟交互作用
  - 外部效度的4个威胁因素
  - 随机分配vs随机抽样的区别

### 📖 《行为科学统计》
- **作者：** Frederick J. Gravetter
- **核心贡献：** 统计方法与研究设计的匹配
- **诊断要点引用：**
  - t检验、ANOVA、回归的适用条件对比
  - 效应量（Cohen's d, η², r）的解读标准
  - 统计检验力分析：1-β ≥ 0.8的行业标准

  - 理论饱和度的判断标准

## 学科特异性标准

### 心理学
- 样本量：实验研究每组≥30，问卷研究≥200
- 信度要求：α≥0.7，重测信度≥0.6
- 报告规范：必须报告效应量和置信区间

### 管理学
- 问卷研究：样本量≥200，SEM研究≥300-500
- 共同方法偏差检验：Harman单因子检验
- 效度检验：区分效度（AVE平方根大于相关系数）

### 医学/公共卫生
- 临床试验：CONSORT规范
- 观察性研究：STROBE规范
- 诊断试验：STARD规范

### 教育学
- 干预研究：每组≥30，聚类设计需考虑组内相关（ICC）
- 问卷研究：Cronbach's α≥0.7，效标关联效度≥0.3

## 统计检验力速查表（G*Power标准）

| 统计方法 | 效应量大小 | 所需总样本量（α=0.05, 1-β=0.8） |
|---------|-----------|-------------------------------|
| 独立样本t检验 | 小(d=0.2) | 637 |
| | 中(d=0.5) | 105 |
| | 大(d=0.8) | 52 |
| 相关分析(r) | 小(r=0.1) | 782 |
| | 中(r=0.3) | 85 |
| | 大(r=0.5) | 28 |
| 多元线性回归 | 小(f²=0.02) | 395 (5个预测变量) |
| | 中(f²=0.15) | 55 (5个预测变量) |
| | 大(f²=0.35) | 24 (5个预测变量) |
| 单因素ANOVA (3组) | 小(f=0.1) | 约900 |
| | 中(f=0.25) | 约150 |
| | 大(f=0.4) | 约60 |

**说明：** 这是总样本量，分组研究需要乘以组数。实际研究中还需增加10-20%作为无效样本缓冲。
